## Publicar en GitHub Pages
1. Repositorio público → subir todos los archivos a la **raíz**.
2. **Settings → Pages → Deploy from a branch → main → / (root) → Save**.
3. Enlace: `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`

## Agregar nuevas semanas
Subir `semana8_mat5_p4.html` y `semana9_mat5_p4.html` a la misma carpeta (mismos nombres). El índice las activa solo.
